# Nivara Architecture — Student Wellbeing Digital Twin

Nivara is an AI-assisted, privacy-preserving student wellbeing platform built for SIH 2026.

## High-Level Architecture
- **Frontend**: React + Vite + TypeScript + TailwindCSS styled with Google Stitch *Serene Equilibrium* tokens (#5b8c83).
- **Backend**: Node.js + Express REST API with strict layered services.
- **Database**: Supabase PostgreSQL schema with Row Level Security (RLS) and identity separation.
- **AI Companion**: Backend-orchestrated empathetic support engine with controlled memory.
- **Safety Engine**: 3-tier deterministic & contextual safety pipeline with Tele-MANAS 14416 integration.
- **Digital Twin**: Personal longitudinal baseline comparator (non-clinical).
